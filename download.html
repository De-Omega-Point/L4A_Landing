A little help getting started

Choose your device.

Complete registration and open the app first. Installation is optional and happens there, not on this download page.

We suggest a guide from your browser. Choose another if it does not match.

iPhone or iPad

Install with Safari

  1. Open the live app in Safari. Register if asked, then open the app from the welcome page.
  2. Tap Safari’s Share button. Depending on your version, it may be inside the browser menu.
  3. Choose Add to Home Screen. Turn on Open as Web App if shown, then tap Add.
  4. Open Loyalty-4-All from your home screen. Check your records before making changes.

If Add to Home Screen is missing, open the page in Safari rather than inside another app. Menu names vary by iOS version.

Android

Install with Chrome

  1. Open the live app in Chrome. Register if asked and use the welcome page’s Install link.
  2. In the app’s installation guide, tap its install button if available and confirm the browser’s prompt.
  3. If no prompt appears, open Chrome’s ⋮ menu and look for Install app or Add to Home screen.
  4. Follow the browser’s confirmation, then open the app from your home screen.

Some devices offer a shortcut instead of a full app installation. If neither option appears, you can continue using the app in Chrome.

Windows, macOS or Linux

Install with Chrome or Edge

  1. Open the live app in Chrome or Edge. Register if asked, then choose Install on the welcome page.
  2. Use the app’s install button when available, or look for an install icon in the address bar.
  3. Alternatively, check the browser menu for Install, Apps or Install this site as an app. Names vary by browser version.
  4. Confirm the browser prompt. Launch the app from your device’s app list or the shortcut your browser provides.

No install option? The app remains available in your browser. Managed work devices may restrict installation.

Mac

Add to Dock with Safari

  1. On macOS Sonoma 14 or later, open the live app in Safari and register if asked.
  2. Choose File → Add to Dock in Safari. You may also find Add to Dock in the Share menu.
  3. Check the name and choose Add, then open the app from the Dock.

Older versions of Safari may not offer Add to Dock. Continue in Safari or use a supported Chrome or Edge installation option. Check your records in the new app window before relying on it.

Any device

Use the app in your browser

  1. Open the live app and complete free registration if asked.
  2. Continue to Community Edition. You do not need to install it to use it.
  3. Bookmark the app in the browser you use for your customer records.

In-app browsers, private browsing and some managed devices may limit installation or storage. If you try another browser, existing local records will not automatically follow you.

Installation help

Good to know.

Why didn’t an installation prompt appear?

This download page cannot install an app from another website. Open the live app first, then use its install guide or your browser menu. Browser eligibility, an existing installation or a previous dismissal can also affect whether a prompt is shown.

Do I need to register again?

New users register on the live app service before using the app. If you already registered, open the app in the same browser and profile. If it asks you to register unexpectedly, return to your original browser and profile or contact support before continuing. Registering again does not recover existing local records. This page cannot read your registration status.

What is my Product ID?

The app service issues your Product ID after registration. It is a reference, not a password, proof of identity or paid access. Your local workspace ID is a separate on-device reference.

Is this a native download or an offline guarantee?

No. This is browser-based installation, not an APK, ZIP or app-store package. Availability and offline behaviour depend on the app and browser. Adding a shortcut does not guarantee offline operation. Google Play, App Store, APK and ZIP downloads remain paused. This is not a native app-store download.
