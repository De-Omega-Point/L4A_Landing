Optional: add the web app to your device

Open the app first. Use your browser’s install option if offered. The option depends on your device and browser.

Android · Chrome or Edge

Open the browser menu and look for Install app or Add to Home screen. If no install option appears, keep using the app in a browser tab.

iPhone or iPad · Safari

Open the app in Safari, tap Share, then look for Add to Home Screen. If it is unavailable, bookmark the app instead.

Desktop

Look for an install icon in the address bar or the browser menu. You can also bookmark the app. Installation is optional.

Adding a shortcut does not guarantee offline operation. Keep backups; installed and browser copies may have separate local storage.
